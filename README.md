# Siam Factory ERP

**Offline-First Factory Management System**

A modular factory management ERP prototype for plastic manufacturing operations.

## Features
- Production and shift tracking
- Orders, customers and invoices
- Raw materials and inventory
- Sales, expenses and reports
- Machines, dies and scrap management
- Dashboard, alerts and analytics
- Local data persistence with IndexedDB
- JSON backup and restore

## Technology Stack
- React 18
- Vite 7
- React Router 7
- Tailwind CSS 3
- IndexedDB
- Recharts
- Lucide React

## Getting Started
Requirements: Node.js 20.19+ and npm.

```bash
npm install
npm run dev
```

Build: `npm run build`
